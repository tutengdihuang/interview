# 240. 生产级RAG：不止向量数据库

## 核心观点

向量库只是组件。生产级RAG要形成数据、检索、生成、评估、反馈五环闭环，做到问题可追溯、效果可迭代。

## 五个环节

1. **数据治理**：清洗去重，管理版本、权限及生效状态；补全文档ID、章节、页码、更新时间、业务线等元数据。
2. **检索质量**：组合关键词BM25、向量检索、重排序。工单号、合同号、错误码、SKU等精确内容应重视关键词匹配；同时处理TopK、阈值、去重和上下文压缩。
3. **生成约束**：要求回答受证据支持，关键结论附来源，证据不足时拒答。召回正确不等于生成必然正确。
4. **分层评估**：分别检查召回命中、重排合理性、生成忠实性、引用准确性；将错误定位到缺知识、检索失败、排序错误或生成幻觉。
5. **反馈回流**：把点踩、追问、人工纠错、无答案等BadCase回流知识库和评测集，适应业务与文档变化。

## 面试口述

生产级RAG不是接一个向量库就结束。先治理文档的质量、版本、权限和元数据；检索用关键词、向量、重排组合；生成要求证据支撑、可引用、证据不足拒答；评估按召回、排序、忠实性和引用分层定位；上线后通过反馈回流持续改进。
