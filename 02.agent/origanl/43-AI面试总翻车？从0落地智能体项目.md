一、开篇描述行业求职现象（视频原话要点）
现在很多面大模型、Agent 岗位的求职者，能背一堆名词：RAG、智能体 Agent、工具调用、Function Call。
求职者可以跟着网上公开教程，在本地把 Demo 跑通，能看到模型调用工具、检索知识库、输出回答。
大部分人简历直接写上 RAG、Agent 项目，自以为具备项目经验，投递岗位。
但是一进入深度面试，面试官不再问 “RAG 是什么、Agent 是什么” 这种基础概念，开始往工程、业务、线上稳定性深挖，大量求职者直接翻车。
二、视频给出【面试翻车现场典型例子】
例子：候选人演示自己做的 Agent Demo，能调用工具查信息，面试官跳过概念提问，直接问落地相关问题，候选人答不上来；
候选人只会描述 “这个 Agent 可以调用工具、用 RAG 检索文档”，说不清楚项目解决了什么业务痛点、为什么选这套技术、线上出问题怎么排查，项目只有玩具 Demo，没有业务边界、异常兜底、运维观测逻辑。

四、视频给出翻车根源结论（明确结论）
翻车根本原因：你只有碎片化 Demo 练习，缺少一套从 0 到 1、可以上线的完整业务项目落地经验。
Demo 只追求 “跑通、能出结果”；线上业务项目必须考虑业务边界、异常兜底、可观测、评估、治理、人机协同，绝大多数自学教程不会教这一部分。
