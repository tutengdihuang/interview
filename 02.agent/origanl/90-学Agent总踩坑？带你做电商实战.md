一、自学 Agent 开发，普遍存在 4 个痛点（视频开篇逐条讲）
时间消耗错位：大量时间耗费在网上零散找资料、本地环境配置、依赖问题、代码报错排查；真正用来思考业务、做项目开发的时间很少。
只会跑代码，不懂设计逻辑：跟着教程复制粘贴，代码最后能运行成功，但是看不懂代码的设计思路，不知道代码为什么要这么写；换一个新需求，自己就独立写不出来。
项目体系割裂，无法沉淀：不同教程、不同开源项目，目录结构、编码风格、技术选型完全不一样。学完 A 项目，再去学 B 项目，要重新适应一套全新代码规范，知识无法沉淀、迁移复用。
碎片化学习，无法产出可上线项目：零散刷短视频、看单篇教程，RAG、LangGraph 等名词都见过，知识点攒了很多，但没有一条连贯主线串联；自己始终没法独立推进一个完整项目，只能跑简单 demo，简历拿不出真实项目。
二、课程基础信息 & 核心剧情设定（课程故事主线案例）
课程名称：《小哲大模型电商 Agent 项目实战课》，项目目标：从零搭建一套完整前后端、可以上线投入使用的电商客服 Agent
剧情背景设定（贯穿全课的例子）：一家电商公司人工客服全部离职，老板交给你任务：使用 AI Agent 顶替人工客服承接用户咨询。

项目最终演进路线：Agent 最开始只能单纯聊天对话 → 持续增加能力，最终做成可控、可查、可测的生产级客服 Agent。

八、对比市面上同类项目课：视频给出明确结论
市面上绝大多数 Agent 实战课通病：直接一次性打包最终成品源码发给学员。学员拿到成品代码，看不到中间迭代过程，不知道每一段代码是在哪个阶段、为了解决什么问题加上去的；很难吃透，学完很难独立复刻。
