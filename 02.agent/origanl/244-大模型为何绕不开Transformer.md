大模型对架构的 3 个硬性要求
不能轻易丢失长距离的上下文信息
训练要支持大规模并行计算，吃满 GPU 算力
模型参数扩大之后，性能还能稳定扩展
RNN（循环神经网络）的两大硬伤
串行计算：必须从左到右逐个词处理，后一步要等前一步算完，很难并行，大模型训练速度极慢。
长距离信息衰减：信息一步步向后传递，句子越长，前面的信息越容易被稀释丢失，类似 “传话游戏越传越失真”。
适合短文本；长文本、千亿参数大模型就扛不住。
CNN（卷积神经网络）的短板
CNN 在图像很强，擅长抓取局部特征；但语言里大量语义关系隔很远（例：虽然…… 但是……）。
想要捕捉远距离关系，只能扩大卷积窗口或者堆很深网络，计算成本暴涨，全局依赖建模不直接。
Transformer 靠自注意力机制解决痛点
直接建立长距离关联：句子中每一个 token 可以直接和任意其他 token 做交互，不用层层传递。比如 “苹果发布新手机”，模型直接关联 “苹果”“发布”“手机”，快速判断指的是公司而不是水果。
训练高度并行：整段文本可以一次性送入同时计算，完美适配 GPU 矩阵运算，千亿级模型才训得动。
极强通用性、可扩展：只要把信息切成一组一组 token，文本、图片、语音、视频都能处理。不只是 NLP 语言模型，大量多模态模型底层也是 Transformer。
总结
不是 RNN、CNN 完全没用，只是大模型时代最核心三点：建模全局关系、利用 GPU 并行算力、支持模型规模化放大，Transformer 全部更擅长，因此成为大模型主流底座。

为什么现在的大模型基本都绕不开 Transformer，而不是继续沿用早期很火的 RNN 或者 CNN？本期视频为你科普。
先看 RNN，也就是循环神经网络。它有两个致命短板。
第一个缺陷，顺序依赖，注定了它快不起来。RNN 必须按顺序处理每个词，没法并行计算，就算算力再强，也只能一个字一个字往后读，训练效率极低。
第二个缺陷，长程遗忘，注定了它笨。只要句子超过几十个词，最开头的信息就几乎完全丢失了，很难捕捉远距离的关联。举个例子，虽然他昨天没睡好，但他今天精神很好。这句话，RNN 很难把句首的他和句尾的精神很好关联起来，因为中间隔太多，信息早就被忘干净了。
然后是 CNN，卷积神经网络。CNN 在图像领域很强，擅长抓取局部特征。但放到语言里，大量语义关系隔得很远。想要捕捉远距离关系，只能扩大卷积窗口，或者堆很深的网络，计算成本会暴涨。所以 CNN 建模全局依赖并不直接。
而真正打破这个困局的破局者，就是 Transformer 架构。2017 年谷歌那篇《Attention Is All You Need》，彻底抛弃了循环结构，全靠注意力机制建模语言关系，直接开启了整个大模型时代，也是如今 GPT、通义千问、Llama 等所有主流大模型的底层基石。
Transformer 凭借自注意力机制，带来三大核心优势：
这就是它的第一个优势：长距离依赖更直接。不管两个词隔得近还是远，只要注意力权重高，它们就能建立联系。这比 RNN 一步步传信息、CNN 一层层扩大视野，都要更直接。
第二个优势是训练时并行能力强。RNN 像一个排队处理系统，前面没算完后面不好开始。而 Transformer 在训练阶段，可以把一整段 token 同时送进去，让不同位置并行计算注意力。这对 GPU 和分布式训练非常友好。到了大模型时代，决定上限的不只是结构能不能表达复杂关系，还包括它能不能消化海量数据、海量参数。Transformer 正好符合这个需求，它可以随着数据、参数、算力一起放大，所以才能支撑从小模型到百亿、千亿参数模型的扩展。
第三个优势是通用、可扩展。文本可以是来源，图片可以切成图像块，音频可以切成声学片段，视频也可以切成一段段时空 token。只要你能把输入变成 token，逻辑就可以用类似的注意力结构去建模它们之间的关系。这就是为什么今天很多多模态模型，不管处理文字、图像、语音还是视频，底层都会向 Transformer 靠拢。它已经不只是一个 NLP 架构，更像一种通用序列建模框架。
最后总结一下：
不是 RNN、CNN 完全不能用，只是做大模型的时候，要同时满足三件事：能捕捉远距离上下文、训练能充分利用 GPU 并行算力、模型放大后效果还能持续提升。这三点，Transformer 全部做得更好。
用一个简单比喻：RNN 就是排队传话，信息从前往后挨个传递，传远了就失真，而且只能串行；CNN 只能看见身边一小片区域；而 Transformer 里，所有词语直接坐在一起开会，互相寻找彼此之间的关联。
