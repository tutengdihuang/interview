【开篇：抛出学习者普遍痛点（视频开头）】
痛点 1：自学 Agent 知识高度碎片化。今天看 RAG、明天看 MCP、随便看一个 Agent 框架，最后只会简单调接口，知识点串不成完整体系。
痛点 2：很多人以为会跑 Demo 就是学会了。大多自学 Demo 只是简单场景，比如写一个查询天气的工具调用 Agent，没有真实业务约束，放到企业级场景完全不够用。
痛点 3：面试考察重点不是名词背诵。面试官不会只问 “什么是 RAG、什么是 Agent”；而是连环追问工程落地类问题，例如架构选型理由、异常怎么处理、幻觉怎么控制、成本怎么优化。只会背定义很容易被问住。
痛点 4：网上教程大多只给最终成品代码。看不到中间迭代过程，看不懂作者为什么要修改这一段代码，遇到 bug 卡住之后很难定位问题根源。
痛点 5：自学缺少面试模拟闭环。自己没法模拟面试官顺着回答持续深挖，不知道自己哪些地方讲不清楚、哪里存在知识盲区。
视频开篇结论：零散自学的方式，很难做出一份能写进简历、扛得住面试深挖的 Agent 项目。
