# MQ消息丢失排查

> **场景定位**：消息队列技术场景  
> **核心设计要点**：全链路防护、生产端/Broker/消费端可信、监控兜底

---

## 🎯 一句话定位

**MQ消息丢失排查解决什么问题？**
```
消息凭空消失
开了持久化、确认机制还是丢
网络重传、消费超时、服务重启
```

---

## 💎 核心观点

**四层防护体系**：
1. **生产端可信**：同步/异步确认、事务消息、本地消息表
2. **Broker端可信**：同步刷盘、主从同步、死信队列
3. **消费端可信**：手动ACK、幂等设计、重试间隔
4. **监控兜底**：全链路追踪、消息回溯、对账系统

---

## 🚀 一句话精华

> **消息不丢失 = 生产端（确认/事务/本地消息表） + Broker端（同步刷盘/主从同步/死信队列） + 消费端（手动ACK/幂等/重试） + 监控兜底（追踪/回溯/对账）**
