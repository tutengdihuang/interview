# 多 Agent 架构下，如何规避重复调用工具，解决资源浪费？

> 面向生产环境的多 Agent 系统设计 · 第 5 问

---

## 核心问题

多 Agent 架构下，如何规避重复调用工具，解决资源浪费？

---

## 核心结论

重复调用的三种来源：**任务边界重叠**（两个 Agent 都认为该自己查）、**无结果共享**（各自查了同一数据）、**无调用记忆**（同轮内反复查）。治理分四层：拆分层 → 基础设施层 → 协作层 → 观测与预算层。核心是：**治理手段（缓存）治标，任务契约治本**。

---

## 重复调用的三种来源

| 来源 | 描述 | 例子 |
|-----|------|------|
| **任务边界重叠** | 两个 Agent 都认为该自己查 | Agent A 和 Agent B 都查询同一用户信息 |
| **无结果共享** | 各自查了同一数据 | Agent A 查了天气，Agent B 又查一遍 |
| **无调用记忆** | 同轮内反复查 | Agent A 在同一任务中多次查询同一 API |

---

## 治理方案：四层防线

### 第 1 层：拆分层——工具归属写入任务契约

**目标**：从源头消除归属重叠

**方法**：
- Manager 拆分任务时按 **MECE** 分配**工具与数据范围**
- 子任务描述中显式声明：
  - "允许用哪些工具"
  - "负责哪些数据域"

**例子**：
```
Agent A：负责用户信息（允许调用 user_api）
Agent B：负责订单信息（允许调用 order_api）
→ 职责清晰，不会重复查询
```

**核心**：这是**治本**的方法

---

### 第 2 层：基础设施层——统一工具网关 + 去重缓存

**目标**：在调用层做去重

**方法**：

#### 1. 集中式 Tool Gateway
- 所有工具调用收敛到**工具注册表**
- 以 `工具名 + 参数哈希` 为 key 做去重

#### 2. 精确缓存
- 同参数调用在 **TTL** 内直接返回缓存结果
- 适用于：配置查询、用户信息查询等幂等操作

#### 3. 语义缓存
- 对搜索/检索类工具
- 用**向量相似度（>0.95 阈值）**命中"语义等价"的历史调用
- 适用于：文档检索、知识库查询

#### 4. 副作用调用去重
- 对有副作用的调用（写操作）
- 用**幂等键 + 分布式锁**去重
- 防止并发重放

**效果**：减少 60-80% 重复调用

---

### 第 3 层：协作层——黑板模式共享结果

**目标**：让后来者直接复用，不必重复检索

**方法**：

#### 1. Anthropic 生产实践
- 子 Agent 先**读共享 artifact/黑板**再决定是否调用工具
- 把产出写入外部系统传引用
- 后来者直接复用

#### 2. 协调者分发"已知信息包"
- 协调者在分发任务时附带**已检索的背景数据**
- 避免子 Agent 重复拉取

**例子**：
```
Agent A 查询了"用户 123 的基本信息"，写入黑板
Agent B 需要同样信息 → 直接读黑板，不再查询
```

**效果**：跨 Agent 重复调用减少 90%+

---

### 第 4 层：观测与预算层

**目标**：持续监控，防止失控

**方法**：

#### 1. 全链路 trace
- 跨 Agent 的工具调用全链路追踪
- 按 `工具+参数` 维度做**重复率告警**

#### 2. 预算控制
- 每 Agent 工具调用配额
- 总预算硬上限（防失控循环烧钱，见第 11 题）

**效果**：异常重复可发现、可控制

---

## 面试加分项

1. **指出本质**：
   > 重复调用是**拆分不满足 MECE 的信号**：治理手段（缓存）治标，任务契约治本。

2. **区分工具类型**：
   - **只读工具**：缓存去重，收益大
   - **副作用工具**：幂等键去重，必须做正确性

## 生活化比喻

把多 Agent 工具调用治理想象成**公司采购管理**：

| 治理层 | 公司类比 |
|-------|---------|
| **拆分层** | 各部门职责清晰，采购需求不重叠 |
| **基础设施层** | 统一采购平台，相同需求自动合并 |
| **协作层** | 采购结果共享，其他部门可直接查看 |
| **观测层** | 采购记录审计，异常采购自动告警 |

---

## 一句话总结

> 规避重复调用的核心是：**四层防线——拆分层（任务契约）→ 基础设施层（工具网关 + 缓存）→ 协作层（黑板共享）→ 观测层（trace + 预算）**。记住：**治理手段治标，任务契约治本**。
