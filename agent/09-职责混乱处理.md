# 长期运行的多 Agent 系统出现职责混乱，怎么处理？

> 面向生产环境的多 Agent 系统设计 · 第 9 问

---

## 核心问题

长期运行的多 Agent 系统出现职责混乱，怎么处理？

---

## 核心结论

职责混乱的根因：**长会话上下文漂移、记忆污染、工具权限随迭代蔓延、对等 Agent 相互"代劳"的涌现行为**。治理分"止血 → 复位 → 防复发"三步。核心是：**角色契约固化 + 任务级无状态子 Agent + 能力注册表强制路由**。

---

## 职责混乱的根因

| 根因 | 描述 | 后果 |
|------|------|------|
| **长会话上下文漂移** | 长对话中角色定义被稀释 | Agent 忘记自己的职责 |
| **记忆污染** | 一个 Agent 的错误结论污染另一个的判断 | 决策质量下降 |
| **工具权限蔓延** | 工具权限随迭代逐渐扩大 | Agent 做超出职责的事 |
| **涌现行为** | 对等 Agent 相互"代劳" | 职责边界模糊 |

---

## 治理方案：三步走

### 第 1 步：止血——检测职责漂移

**目标**：及时发现问题

#### 1. 行为监控
- trace 每个 Agent **实际调用的工具分布**
- 与**注册的职责声明**比对
- Agent A 频繁调用属于 Agent B 的工具 → **漂移信号**

#### 2. 语义监控
- 对 Agent 输出做**聚类**
- 若多个 Agent 输出**语义重叠度持续升高**（多样性坍缩）
- 说明职责边界已被侵蚀

#### 3. 回归评测
- 维护**角色行为评测集**
  - 每个角色的输入应路由给谁
  - 输出应符合什么格式
- 作为 CI 之外的**运行时探针**

**效果**：职责漂移可发现、可度量

---

### 第 2 步：复位——恢复清晰边界

**目标**：恢复 Agent 的清晰职责

#### 1. 角色契约固化
- **Agent = 模型 + 系统提示词 + 工具集** 的三元组
- 提示词**版本化管理**
- 职责混乱常来自提示词被运行时软修改或长对话稀释
- **恢复出厂契约**即可复位

#### 2. 上下文复位
- **长生命周期共享对话是漂移温床**
- 生产实践倾向**任务级无状态子 Agent**
  - 每次任务独立上下文
  - 需要延续的信息走**显式持久化记忆**（计划、结论存外部存储）
  - 而非依赖会话残留
- **Anthropic 的做法**：主控把计划存入 Memory，子 Agent 各自独立上下文

#### 3. 记忆治理
- **定期压缩/清理陈旧记忆**
- **隔离各 Agent 的记忆命名空间**
- 防止一个 Agent 的错误结论污染另一个的判断

**效果**：Agent 职责清晰、上下文干净

---

### 第 3 步：防复发——架构级约束

**目标**：从架构上防止职责混乱再次发生

#### 1. 能力注册表 + 编排层强制路由
- 任务由**编排器按注册能力分发**
- 而不是 Agent 自己"认领"
- **委派校验**时要求：请求任务 ⊆ 目标 Agent 的注册能力（同第 7 题 L2 层）
- 越界请求**直接拒绝**

#### 2. 权限收敛
- 工具权限**定期审计回收**
- 与职责声明做 **diff**
- 长期不用的权限**自动降权**

#### 3. 职责单一性作为拆分原则
- 新增职责优先**新建 Agent** 而不是给现有 Agent 加职责
- "角色边界"本身当作**受版本管理的接口**

**效果**：职责边界刚性化，不可随意突破

---

## 面试加分项

**类比微服务的"服务边界腐化"**：
> 解法相同——**契约先行**（typed contract）、**注册发现**（registry）、**运行时治理**（路由强制），而不是靠自觉。

---

## 生活化比喻

把多 Agent 职责治理想象成**公司组织管理**：

| 治理步骤 | 公司类比 |
|---------|---------|
| **止血：检测漂移** | 审计员工实际工作内容 vs 岗位职责 |
| **复位：恢复边界** | 重新明确部门职责，轮岗 Reset |
| **防复发：架构约束** | 完善组织架构，明确汇报关系，新增职能先设新部门 |

**关键**：
- **角色契约** = 岗位说明书
- **任务级无状态** = 项目制，项目结束团队解散
- **能力注册表** = 组织架构 + 职责清单
- **强制路由** = 任务必须通过领导分配，不能自己认领

---

## 一句话总结

> 职责混乱的治理是**三步走**：止血（检测漂移）→ 复位（恢复边界）→ 防复发（架构约束）。核心是：**角色契约固化 + 任务级无状态子 Agent + 能力注册表强制路由**。记住：职责边界要刚性化，不可随意突破。
